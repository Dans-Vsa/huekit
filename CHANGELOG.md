# Changelog

## 1.0.0 - 2026-11-28

First stable release.

### Added
- WCAG 2.x contrast checker with live preview and a passing text color suggestion
- Harmony palettes and a 50-900 shade scale
- Image palette extractor (k-means, runs locally)
- Export to CSS variables, Tailwind config or JSON
- Saved palettes in `localStorage`
- Skip link, visible control borders and focus handling after deleting a palette
- GitHub Actions CI on Node 22 and 24
